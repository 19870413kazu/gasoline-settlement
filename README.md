# 🚗 ガソリン代精算 Webアプリ (パターンB仕様)

Googleマップのタイムライン（JSON）をアップロードし、業務移動ログを選択・修正して精算CSVを出力するWebツールです。

## 🛡️ 仕様とセキュリティ (パターンB)
- **距離改ざん不可:** GPSから算出された実測距離(km)は編集不可（固定）とし、不正申請を防止します。
- **住所・手段の編集可能:** GPS住所を「営業所名」や「施設名」へ補正可能です。
- **データ非保持 (No-DB):** 個人位置情報はメモリ上のみで即時処理され、データベースやサーバーへ保存されません。

## 🛠️ 環境変数 (Vercel)
- `GOOGLE_MAPS_API_KEY`: Google Maps Geocoding API認証キー
- `DEFAULT_PRICE_PER_KM`: キロ単価（初期設定: 15）
